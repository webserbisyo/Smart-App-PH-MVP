## Goal

Every Supabase Auth email (sign-up code, sign-in code, password reset code) goes out through Resend from the platform domain and shows a 6-digit code, never a link.

Codes instead of links on purpose: no redirect URL allow-list to maintain for preview links, it works the same in the Vite dashboard, the storefront and the future Capacitor app, and owners can type the code on another device.

## Build only (in the repo)

- `supabase/templates/` with four HTML templates, short, plain, mobile-friendly, text from the words below, each showing `{{ .Token }}` large and no `{{ .ConfirmationURL }}`:
  - `confirmation.html` (owner sign-up and a new customer's first code), subject "Your Smart App PH code"
  - `magic_link.html` (customer sign-in code), subject "Your sign-in code"
  - `recovery.html` (owner password reset), subject "Reset your password"
  - `email_change.html`, subject "Confirm your new email"
- `supabase/config.toml`: point `[auth.email.template.*]` at those files; `[auth.email]` `otp_length = 6`, `otp_expiry = 900`, `enable_confirmations = true`; `[auth]` `minimum_password_length = 8`. These drive the local stack and document the hosted settings.
- `docs/deploy.md`: a "Resend and Auth email" section with the by-hand steps below.
- `docs/decisions.md`, under "## Phase 2": `P2-4: Auth emails use 6-digit codes only (no links), sent by Resend SMTP from mail.<domain>.`

## Do not build

- No sign-up or sign-in screens (P3b), no order emails (after launch), no Edge Functions, no Resend SDK in code.

## What the founder does by hand (in `docs/deploy.md` and in your final reply)

Keys go into Supabase and Resend settings, never into chat or the repo.

1. Resend → Domains → Add `mail.<domain>`, region closest to Singapore (Tokyo `ap-northeast-1` if offered). Add the DNS records it shows (SPF, DKIM, MX for `send`) in Vercel → Domains → `<domain>` → DNS. Wait for "Verified".
2. Resend → API Keys → create `supabase-smtp`, permission "Sending access", domain `mail.<domain>`.
3. Supabase → Authentication → Emails → SMTP Settings → enable custom SMTP: host `smtp.resend.com`, port `465`, username `resend`, password = that API key, sender `codes@mail.<domain>`, sender name `Smart App PH`.
4. Supabase → Authentication → Emails → Templates: paste the subject and body of the four templates from `supabase/templates/`.
5. Supabase → Authentication → Sign In / Providers → Email: Confirm email on, OTP length 6, OTP expiry 900 seconds, minimum password length 8.
6. Supabase → Authentication → Rate Limits: emails sent per hour 100.
