## Goal

A customer opens a shop link on a phone, sees whether it is open, browses and searches the menu, picks options in the item sheet and builds a cart that survives a reload.

## Read first

`CLAUDE.md`, `docs/ux-plan.md` sections 3, 5.1 to 5.4 and 7, the storefront hooks and server functions P5.2 added, the P4.0 patterns. Plan first; if something you need is missing from `get_storefront`, stop and say what.

## Build only

In `apps/storefront/src/app/[shop]/` and `src/features/<area>/`:

1. **Data:** the layout and pages read the shop with `get_storefront` on the server (replace `getShopStub`). Pages never read the session on the server (they stay cacheable). Pending or suspended shops show "This shop isn't open yet"; unknown slugs show not found. The shop's `theme-color` and title come from the data.
2. **Home** (`/[shop]`): `ShopHeader` with open state ("Open · until 9 PM" / "Closed · opens 7 AM tomorrow" from `openState`), cover (`next/image` with `sizes`), members line when `memberCount` is not null, category chips (`scroller` + `CategoryIcon`, linking to the menu section), Best sellers (`scroller` of `ProductCard`), Messenger button when set. Closed or paused: an `alert` under the header.
3. **Menu** (`/[shop]/menu`): sticky search and category chips (tap scrolls to the section; scrolling highlights the chip), sections with a 2-column `ProductCard` grid (3 to 4 on desktop), "from" prices, sold-out cards greyed and not addable, client-side search with an empty state and Clear.
4. **Item sheet** (`ResponsiveDialog`): photo strip, name, description, required variant (`radio-group`, sold-out options disabled), add-on groups (`checkbox` up to N, or radio when max 1), note (120 chars), `StickyActionBar` with `QuantityStepper` and "Add · ₱150" (live). Missing required choice: the button says what to choose and scrolls there. Quick add from "+" when the item has one variant and no required add-ons. Add = toast, cart bar bump, `navigator.vibrate(10)` when supported.
5. **Cart:** a client store per shop in local storage (`smartapp.cart.<slug>`, wrapped in try/catch), lines as `CartLine` from `packages/core`. The cart bar shows count and subtotal; the cart `ResponsiveDialog` shows `OrderLines` with `QuantityStepper`, remove, note, subtotal and "Checkout · ₱345" (links to `/[shop]/checkout`, built in P4.4; until then it shows the existing empty page). Lines whose item or variant no longer exists are flagged and removable.
6. Closed or paused shop: Add buttons are disabled with the reason; the cart still opens.

## Do not build

- Checkout, receipt, member stamps in the cart (P4.4, P4.6), install prompt, offline page, per-shop icons (P6), dark mode, reviews, favourites.

## Rules

- `pnpm check` green. Unit-test the cart store (add same item with same options merges; different options make a new line; totals in centavos).
- Server components by default; client components only for the cart, sheets and search. No new packages. No `any`, no casts, no `@ts-ignore`. Never read or print `.env.local`.
