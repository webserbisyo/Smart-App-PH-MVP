# Smart App PH (MVP)

Installable ordering app and owner dashboard for small Philippine shops. Start with `AGENTS.md` (the rules for every agent and person), then `docs/system-paper.md`, the blueprints in
`docs/blueprints/`, and `docs/PROGRESS.md`.

```
pnpm install   # Node 24 LTS
pnpm check     # typecheck + lint + test
```
